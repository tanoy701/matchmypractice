# Match My Practice

Static B2B landing page: AI client-intake automation for private practices. RACE stage: **Acquire**.

## Files
- `index.html`, `styles.css`, `script.js`: the page (no build step)
- `vercel.json`: static hosting config with basic security headers

## Before going live
1. Get a free access key at https://web3forms.com and replace `YOUR_WEB3FORMS_ACCESS_KEY` in `index.html`. Until then the form shows a "not live yet" message instead of submitting.
2. Edit the copy if the audience or offer changes (target audience, service and value proposition are set in the hero).

## Deploy
Vercel: import the GitHub repo, framework preset "Other", no build command, output directory is the root.
